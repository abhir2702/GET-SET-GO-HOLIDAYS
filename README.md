# GET SET GO HOLIDAYS 🌎✈️

A modern travel booking website built with React and TypeScript, offering customized tour packages across India and international destinations.

## 🌟 Features

- 🎯 Responsive design for all devices
- 🔍 Advanced tour search functionality
- 🌍 Indian and International tour packages
- 💼 Customizable tour booking
- 📱 WhatsApp integration for instant booking
- 🔒 Enhanced security features
- 📊 Interactive tour statistics and analytics
- 🎨 Modern UI with animations

## 🛠️ Technology Stack

- **Frontend Framework**: React 18.x
- **Language**: TypeScript
- **Build Tool**: Vite
- **UI Components**: 
  - shadcn/ui
  - Radix UI primitives
  - Lucide icons
- **Styling**: 
  - Tailwind CSS
  - Framer Motion for animations
- **State Management**: React Query
- **Form Handling**: React Hook Form
- **Data Visualization**: Tremor, Recharts
- **Security**: Built-in CSRF protection, rate limiting

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd GET-SET-GO
```

2. Install dependencies:
```bash
npm install
```

3. Create a .env file in the root directory:
```env
VITE_WHATSAPP_CONTACT=your_whatsapp_number
VITE_COMPANY_EMAIL=your_email
VITE_SUPPORT_EMAIL=your_support_email
VITE_COMPANY_PHONE=your_phone_number
```

4. Start the development server:
```bash
npm run dev
```

## 🚀 Build and Deployment

1. Create a production build:
```bash
npm run build
```

2. Preview the production build:
```bash
npm run preview
```

The build files will be in the `dist` directory, optimized and ready for deployment.

## 🏗️ Project Structure

- `/src`
  - `/assets` - Images and static files
  - `/components` - Reusable UI components
  - `/config` - Environment and app configuration
  - `/data` - Tour data and static content
  - `/hooks` - Custom React hooks
  - `/lib` - Utility functions and security
  - `/pages` - Main application pages
  - `/types` - TypeScript type definitions

## 🔐 Security Features
